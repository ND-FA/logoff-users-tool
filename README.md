# LogoffUsersTool

**LogoffUsersTool** — это утилита с графическим интерфейсом для системных администраторов, предназначенная для автоматизации процесса завершения сеансов пользователей на удаленных серверах Windows. Программа позволяет отправлять периодические предупреждения пользователям перед принудительным завершением сеанса по истечении заданного таймера.

![image](https://github.com/user-attachments/assets/eed60444-9701-437f-ae8d-54045661a798)


## ✨ Ключевые возможности

- **Графический интерфейс:** Удобное управление всеми функциями из одного окна.
- **Поиск и добавление серверов:**
  - Автоматический поиск серверов в домене Active Directory.
  - Возможность ручного добавления и удаления серверов.
- **Гибкая настройка таймеров:**
  - **Основной таймер:** Задает общее время до принудительного завершения сеансов.
  - **Интервал уведомлений:** Определяет, как часто пользователи будут получать предупреждающие сообщения.
- **Кастомизация:**
  - Возможность задать собственный текст предупреждающего сообщения.
  - Исключение определенных учетных записей (например, служебных) из процесса завершения сеансов.
- **Безопасность:**
  - **Остановка при изменении настроек:** Любой запущенный процесс автоматически прекращается при сохранении новых параметров, чтобы избежать работы с устаревшими данными.
  - **"Чистый" запуск:** Приложение всегда запускается с пустым списком выбранных серверов, требуя осознанного выбора от администратора.
- **Структурированное логирование:** Все операции отображаются в виде иерархического дерева. Сообщения автоматически группируются по серверам и категориям (Информация, Успешно, Предупреждения, Ошибки), а счетчики сообщений позволяют быстро оценить ситуацию.
- **Сохранение настроек:** Программа запоминает общие параметры, а также размер и положение окна между сеансами.

## ⚙️ Требования

- **ОС:** Windows.
- **Платформа:** .NET 9.0 Desktop Runtime.
- **PowerShell:** Необходим для выполнения команд на удаленных серверах.
- **Права доступа:** Учетная запись, из-под которой запускается программа, должна иметь права на:
  - Чтение списка серверов из Active Directory (`Get-ADComputer`).
  - Выполнение удаленных команд PowerShell.
  - Запрос сессий (`quser`), отправку сообщений (`msg`) и завершение сеансов (`logoff`) на целевых серверах.

## 🚀 Как использовать

### 1. Начальная настройка

![image](https://github.com/user-attachments/assets/de5c8e11-f966-4b7b-a17c-b06aa99ebdda)



1.  **Откройте Настройки:** Нажмите на кнопку **"Настройки" (⚙️)** в главном окне.
2.  **Управление серверами:**
    - **Поиск:** Нажмите **"Поиск"**, чтобы автоматически найти серверы в домене. Они добавятся в общий список.
    - **Добавление вручную:** Введите имя сервера в текстовое поле и нажмите **"Добавить"**. Серверы, добавленные вручную, можно удалить из списка кнопкой **"Удалить"** (она активна, только когда выбран такой сервер).
3.  **Выберите целевые серверы:** Поставьте галочки напротив серверов, на которых нужно будет завершать сеансы.
4.  **Настройте параметры:**
    - **Таймер до выхода:** Установите общее время в секундах, по истечении которого сеансы будут принудительно завершены.
    - **Интервал уведомлений:** Укажите, как часто (в секундах) отправлять пользователям предупреждения.
    - **Сообщение для пользователей:** Введите текст, который увидят пользователи.
    - **Исключаемые пользователи:** Если нужно, включите опцию и перечислите через точку с запятой (`;`) логины пользователей, которых не нужно отключать.
5.  **Сохраните настройки:** Нажмите **"Сохранить"**.

### 2. Запуск и мониторинг

1.  **Запуск:** В главном окне нажмите кнопку **"Старт"**. Кнопка активна только в том случае, если в настройках выбран хотя бы один сервер.
2.  **Процесс:** Программа начнет обратный отсчет, отображая оставшееся время на прогресс-баре. В соответствии с заданным интервалом, она будет опрашивать серверы и отправлять уведомления активным пользователям.
3.  **Мониторинг:** Отслеживайте выполнение в реальном времени в окне структурированного журнала. Логи автоматически группируются по серверам и категориям, что позволяет легко сворачивать и разворачивать ветки для анализа. Сообщения окрашены в зависимости от их типа (информация, успех, предупреждение, ошибка).
4.  **Остановка:** Нажмите кнопку **"Стоп"** в любой момент, чтобы немедленно прервать все операции.
5.  **Завершение:** По истечении таймера программа попытается принудительно завершить все сеансы (кроме исключенных) на выбранных серверах.

Проект написан на C# с использованием Windows Forms и .NET 9.

### Сборка из исходного кода

1.  Клонируйте репозиторий.
2.  Откройте проект в Visual Studio 2022 или новее.
3.  Для сборки проекта выполните команду в терминале:
    ```bash
    dotnet build
    ```
Готовый исполняемый файл будет находиться в папке `bin/Debug/net9.0-windows/`.
