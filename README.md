## 🚀 Основные возможности

- **Графический интерфейс:** Удобное управление всеми функциями из одного окна.

- **Работа с серверами:**
  - Автоматический поиск серверов в домене Active Directory.
  - Возможность ручного добавления и удаления серверов.
  - **Фильтр списка серверов:** Быстрый поиск нужных серверов прямо в окне настроек.

- **Гибкая настройка процесса:**
  - **Основной таймер:** Задает общее время до принудительного завершения сеансов.
  - **Интервал уведомлений:** Определяет, как часто пользователи будут получать предупреждающие сообщения.
  - **Кастомизация сообщения:** Возможность задать собственный текст предупреждения.
  - **Исключение пользователей:** Исключение определенных учетных записей (например, служебных) из процесса.

- **Эргономика и интерфейс:**
  - **Темы оформления:** Возможность переключения между светлой и темной темами.
  - **Управление одним кликом:** Мгновенное снятие или установка галочки на сервере одним нажатием.
  - **Запоминание состояния:** Программа сохраняет размер и положение окна между сеансами.
  - **Опциональное сохранение выбора:** Выбранные серверы и другие параметры могут сохраняться между запусками, если это указано в настройках.

- **Безопасность и надежность:**
  - **"Чистый" запуск по умолчанию:** Если сохранение настроек не включено, приложение запускается с пустым списком выбранных серверов, требуя осознанного выбора от администратора.
  - **Валидация настроек:** Приложение не позволит сохранить конфигурацию с пустым списком серверов, предотвращая случайные ошибки.
  - **Остановка при изменениях:** Любой запущенный процесс автоматически прекращается при сохранении новых параметров, чтобы избежать работы с устаревшими данными.

- **Структурированное логирование:** 
  - Все операции отображаются в виде иерархического дерева.
  - Сообщения автоматически группируются по серверам и категориям (Информация, Успешно, Предупреждения, Ошибки).
  - Встроенные счетчики сообщений позволяют быстро оценить ситуацию.

- **Надежная асинхронная архитектура:**
  - Улучшена отзывчивость интерфейса во время выполнения фоновых операций.
  - Гарантируется строгая последовательность: система сначала дожидается завершения всех задач по отправке уведомлений и только после этого приступает к принудительному завершению сеансов, что исключает "состояния гонки" (*race conditions*).

## 🛠️ Как использовать

1.  **Запустите приложение:** Скачайте последнюю версию из раздела [Releases](https://github.com/BlackDVK/LogoffUsersTool/releases/latest) и запустите `LogoffUsersTool.exe`.

2.  **Перейдите в настройки:** Нажмите на иконку шестеренки (⚙️) в правом верхнем углу, чтобы открыть окно настроек.

3.  **Наполните список серверов:**
    - **Способ А (Автопоиск):** Нажмите кнопку **"Найти серверы"**, чтобы автоматически обнаружить терминальные серверы в вашем домене.
    - **Способ Б (Ручное добавление):** Введите имя сервера в текстовое поле и нажмите **"Добавить"**.

4.  **Выберите целевые серверы:**
    - Установите галочки напротив тех серверов, на которых нужно завершить сеансы. Клик по любой части строки элемента моментально установит или снимет галочку.
    - *Совет:* Если список большой, воспользуйтесь полем **"Фильтр"** над списком, чтобы быстро найти нужные серверы.

5.  **Задайте параметры:**
    - **Таймер до отключения:** Установите общее время в секундах, по истечении которого сеансы будут принудительно завершены (например, 3600 секунд для 1 часа).
    - **Интервал уведомлений:** Укажите, как часто (в секундах) пользователи будут получать предупреждения (например, 900 секунд для 15 минут).
    - **Сообщение:** Введите текст сообщения, которое будет отправлено пользователям.
    - **Исключаемые пользователи:** Если нужно, включите опцию и перечислите через точку с запятой (`;`) логины пользователей, которых не нужно отключать.

6.  **Сохраните настройки:** Нажмите **"Сохранить"**. Если вы хотите, чтобы все эти параметры (включая выбор серверов) сохранялись между запусками, отметьте галочку **"Сохранять настройки"**. *Внимание: сохранить пустой список серверов невозможно.*

7.  **Запустите процесс:** Вернувшись на главный экран, нажмите кнопку **"Начать"**. Процесс можно остановить в любой момент кнопкой **"Стоп"**.
